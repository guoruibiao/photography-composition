# 摄影构图口诀1000句

手机也能拍出大片感

- 在线使用：https://ELSA-was.github.io/photography-composition/
- 产品介绍页：https://ELSA-was.github.io/photography-composition/details.html
- 产品说明书：[产品说明书.md](./产品说明书.md)

## 适合谁

摄影新手、旅行爱好者、想提升出片的人

## 包含内容

- 10 个场景 × 100 句，共 1000 句中英对照
- 每个场景配套 **示例视频**（对话演示）与 **示例对话音频**，页面内点击即播
- 每场景 2 段情景对话 + 核心速记要点
- 6 条通用豆包 AI 陪练指令 + 10 条场景专属指令

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 产品主页面（需输入密码进入），含全部内容、示例音视频与陪练指令 |
| `details.html` | 产品介绍页（公开，无密码） |
| `media/` | 每个场景的示例视频（`.mp4`）与示例对话音频（`.mp3`） |
| `产品说明书.md` | 产品定位、使用场景、定价、使用说明 |
| `内容源-*.md` | 全部正文内容源文件 |
| `豆包AI陪练指令包.md` | 6 条通用 + 每场景专属指令 |

## 密码说明

主页面 `index.html` 需要输入访问密码，密码由卖家在购买后单独发送。
页面内只保存不可逆的加盐 SHA-256 校验值，**不含密码明文，也不含任何可逆编码**。

> 这是浏览器端访问控制，能防止随手转发，但并非绝对加密，请勿视为强安全保护。
